# Exam technique: AS English Literature

How the AS papers work and how marks are given. Details marked *(to verify)* need checking against the syllabus and a recent mark scheme.

## The papers

- **Paper 1, Drama and Poetry:** one question on the drama set text and one on the poetry set text. Each text offers a passage-based question and an essay question *(to verify)*.
- **Paper 2, Prose and Unseen:** one question on the prose set text, then a critical response to an unseen poem, prose extract or drama extract.
- Split the time evenly between the two answers, with about 10 minutes of planning for each *(lengths to verify)*.

## Passage-based questions

- Read the passage twice. Work out what it does in the whole text: where it comes, and what changes in it.
- Analyse its language, form and structure closely, then link it to the rest of the text.

## Essay questions

- Answer the question in the first paragraph: an argument, not a summary.
- Each paragraph makes one point, then gives a short quotation, analyses its effect, and links it back to the question.
- Use context only where it explains the text.

## The unseen

1. First reading: what is it about, and what is its mood?
2. Second reading: form, structure and language. Note three or four features that create the effect.
3. Organise the answer around ideas, not features: what the text does, and how.

## How the marks are given

The assessment objectives cover knowledge of the text, analysis of language, form and structure, a personal response that answers the question, and context *(to verify)*. Answers are marked in levels, so a clear argument with close analysis throughout beats a long list of techniques.

## This loses marks

- Retelling the plot instead of answering the question.
- Naming techniques without saying what effect they create.
- Long quotations with little comment on them.
