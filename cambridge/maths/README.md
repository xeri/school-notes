## Exam technique

- **Pace:** about 1.5 minutes a mark on both papers. A stuck question gets no more than its marks' worth of minutes.
- **Accuracy:** non-exact answers to 3 significant figures, and angles in degrees to 1 decimal place, unless the question says otherwise. Keep more figures in the working.
- **"Exact"** (surds, π) means no decimals.
- **"Show that"** means every step written down, with the given result as the last line.
- **Radians** for calculus and circular measure.
- **Marks:**
  - **M** marks are for a method; **A** marks are for accuracy and need the M mark before them; **B** marks stand alone.
  - Shown working earns follow-through marks after an earlier error. A bare wrong answer earns nothing.
- **Formula list:** a list of formulae and statistical tables (MF19) is provided *(to verify)*. A scientific calculator is expected; check which are allowed *(to verify)*.
- **Paper 5:**
  - Name the variable and its distribution first, e.g. X ~ B(10, 0.3).
  - For a normal question, sketch the curve and shade the region before standardising.
  - Use a continuity correction whenever the normal approximates a discrete distribution.

**This loses marks:**
- rounding too early;
- missing trig solutions outside the first quadrant;
- a forgotten + C or ±;
- degrees where radians were needed.

## How to study it

- Do past-paper questions on a topic as soon as it's written up. Mark them with the mark scheme, and redo every lost mark two days later.
- Derive rather than memorise where you can. Learn by heart only what the formula list doesn't give.
- Recognising the question type is half the work: for a batch of questions, name the first step of each before solving any.
