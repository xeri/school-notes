# Mathematics formulas

The course page says the **surface area and volume formulae for the sphere, pyramid and cone** will be given in the exam. A question may also state a result it needs (the 2025 final did this for a circle-lengths result). Nothing else is promised, so learn everything below. The final question papers are not in the sources, so whether a printed formula sheet is supplied is unconfirmed.

## Number

| | |
|---|---|
| Compound interest | $P\left(1+\dfrac{r}{100}\right)^n$ — $P$ invested, $r$% per year, $n$ years; the formula gives the total value, not the interest |
| Depreciation | $P\left(1-\dfrac{r}{100}\right)^n$ |
| Simple interest | $I = \dfrac{Prt}{100}$ — $r$% per year, $t$ in years |
| GST (NZ, 15%) | price excluding GST $=$ price including GST $\div1.15$ |
| Percentage change | $\dfrac{\text{change}}{\text{original}}\times100$ |
| Reverse percentage | divide by the multiplier |
| Average speed | $\dfrac{\text{total distance}}{\text{total time}}$ |
| Standard form | $A\times10^n$, $1\leqslant A<10$ |

**Index laws:** $a^ma^n = a^{m+n}$, $\dfrac{a^m}{a^n} = a^{m-n}$, $(a^m)^n = a^{mn}$, $a^0 = 1$ ($a\neq0$), $a^{-n} = \dfrac{1}{a^n}$, $a^{m/n} = \left(\sqrt[n]{a}\right)^m$

**Surds:** $\sqrt{ab} = \sqrt a\sqrt b$, $\sqrt{\dfrac ab} = \dfrac{\sqrt a}{\sqrt b}$, $\dfrac{1}{\sqrt a} = \dfrac{\sqrt a}{a}$, $\dfrac{1}{a-\sqrt b} = \dfrac{a+\sqrt b}{a^2-b}$

## Algebra

| | |
|---|---|
| Quadratic formula | $x = \dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$ for $ax^2+bx+c = 0$, $a\neq0$ |
| Discriminant | $b^2-4ac$: $>0$ two roots, $=0$ one repeated root, $<0$ no real roots |
| Completing the square | $x^2+bx+c = \left(x+\tfrac b2\right)^2-\tfrac{b^2}{4}+c$ |
| Difference of two squares | $a^2-b^2 = (a+b)(a-b)$ |
| Linear $n$th term | $dn + (a_1-d)$ |
| Geometric $n$th term | $ar^{n-1}$ |
| Quadratic sequence | $n^2$ coefficient $=\tfrac12\times$ second difference |
| Direct variation | $y = kx$ |
| Inverse variation | $y = \dfrac kx$ |
| Composite function | $gf(x) = g[f(x)]$ |

## Coordinate geometry

| | |
|---|---|
| Straight line | $y = mx+c$ |
| Line through $(x_1, y_1)$ | $y-y_1 = m(x-x_1)$ |
| Gradient | $m = \dfrac{y_2-y_1}{x_2-x_1}$ |
| Length | $\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$ |
| Midpoint | $\left(\dfrac{x_1+x_2}{2}, \dfrac{y_1+y_2}{2}\right)$ |
| Parallel | same $m$ |
| Perpendicular | $m_1m_2 = -1$, i.e. $m_2 = -\dfrac{1}{m_1}$ (neither line vertical) |

## Calculus

| | |

## Mensuration

**To recall:**

| | Area / Volume | Surface area |
|---|---|---|
| Rectangle | $lw$ | — |
| Triangle | $\tfrac12 bh$ | — |
| Parallelogram | $bh$ | — |
| Trapezium | $\tfrac12(a+b)h$ | — |
| Circle | $\pi r^2$, $C = 2\pi r = \pi d$ | — |
| Arc length ($\theta$ in degrees) | $\dfrac{\theta}{360}\times2\pi r$ | — |
| Sector area ($\theta$ in degrees) | $\dfrac{\theta}{360}\times\pi r^2$ | — |
| Cuboid | $lwh$ | $2(lw+lh+wh)$ |
| Prism | cross-section $\times$ length | sum of faces |
| Cylinder | $\pi r^2h$ | $2\pi r^2+2\pi rh$ (closed); curved part $2\pi rh$ |

**Given in the exam:**

| | Volume | Surface area |
|---|---|---|
| Sphere | $\tfrac43\pi r^3$ | $4\pi r^2$ |
| Cone | $\tfrac13\pi r^2h$ | $\pi rl$ (curved); add $\pi r^2$ for the base |
| Pyramid | $\tfrac13\times$ base area $\times h$ | sum of faces |

$h$ is the perpendicular height. Cone slant height: $l = \sqrt{r^2+h^2}$. A hemisphere is half a sphere: volume $\tfrac23\pi r^3$, curved surface $2\pi r^2$.

Units: lengths in cm, areas in cm², volumes in cm³. Convert every length to the same unit before substituting.

**Conversions:** $1\ \text{cm}^2 = 100\ \text{mm}^2$, $1\ \text{m}^2 = 10^4\ \text{cm}^2$, $1\ \text{cm}^3 = 1000\ \text{mm}^3$, $1\ \text{m}^3 = 10^6\ \text{cm}^3$, $1\ \text{litre} = 1000\ \text{cm}^3$.

## Trigonometry

| | |
|---|---|
| Pythagoras | $a^2+b^2 = c^2$ |
| Sine | $\sin\theta = \dfrac{\text{opp}}{\text{hyp}}$ |
| Cosine | $\cos\theta = \dfrac{\text{adj}}{\text{hyp}}$ |
| Tangent | $\tan\theta = \dfrac{\text{opp}}{\text{adj}}$ |
| Sine rule | $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$ (side $a$ is opposite angle $A$) |
| Sine rule (angle) | $\dfrac{\sin A}{a} = \dfrac{\sin B}{b}$ |
| Cosine rule | $a^2 = b^2+c^2-2bc\cos A$ ($A$ is the angle between $b$ and $c$) |
| Cosine rule (angle) | $\cos A = \dfrac{b^2+c^2-a^2}{2bc}$ |
| Area of a triangle | $\tfrac12 ab\sin C$ ($C$ is the angle between $a$ and $b$) |
| Obtuse sine | $\sin(180°-\theta) = \sin\theta$ |
| Obtuse cosine | $\cos(180°-\theta) = -\cos\theta$ |
| $y = a\sin bx$, $y = a\cos bx$ | amplitude $a$, period $\dfrac{360°}{b}$ |

## Vectors and matrices

| | |
|---|---|
| Magnitude | $\left|\begin{pmatrix}x\\y\end{pmatrix}\right| = \sqrt{x^2+y^2}$ |
| Vector between points | $\overrightarrow{AB} = \mathbf{b}-\mathbf{a}$ |
| Midpoint position vector | $\tfrac12(\mathbf{a}+\mathbf{b})$ |
| Determinant | $|A| = ad-bc$ |
| Inverse | $A^{-1} = \dfrac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$, only if $ad-bc\neq0$ |
| Identity | $\begin{pmatrix}1&0\\0&1\end{pmatrix}$ |

## Statistics and probability

| | |
|---|---|
| Probability | $\dfrac{\text{favourable}}{\text{total}}$ |
| Complement | $P(\text{not }A) = 1-P(A)$ |
| Relative frequency | $\dfrac{\text{successes}}{\text{trials}}$ |
| Expected frequency | $P\times$ trials |
| Mean | $\dfrac{\sum x}{n}$ |
| Mean from a table | $\dfrac{\sum fx}{\sum f}$ |
| Estimated mean (grouped) | $\dfrac{\sum f\times\text{midpoint}}{\sum f}$ |
| Frequency density | $\dfrac{\text{frequency}}{\text{class width}}$ |
| Pie chart angle | $\dfrac{f}{\text{total}}\times360°$ |
| Interquartile range | $Q_3-Q_1$ |
| Quartile positions (cumulative frequency curve) | $Q_1$ at $\tfrac n4$, $Q_2$ at $\tfrac n2$, $Q_3$ at $\tfrac{3n}{4}$ |
