Pre-Q Basic	Discrete data?	Takes separate values (e.g. counts)	
Pre-Q Basic	Continuous data?	Can take any value in a range (measurements)	
Pre-Q Basic	Mean?	Sum of values ÷ number of values, \(\frac{\sum x}{n}\)	
Pre-Q Basic	Median?	The middle value when ordered	
Pre-Q Basic	Mode?	The most frequent value	
Pre-Q Basic	Range?	Highest value − lowest value	
Pre-Q Basic	Interquartile range (IQR)?	Spread of the middle half: \(Q_3-Q_1\)	
Pre-Q Basic	Modal class?	Class with the highest frequency (highest density if widths differ)	Unequal widths?
Pre-Q Basic	Possibility diagram?	A grid showing all outcomes of two events	
Pre-Q Basic	Extrapolation?	Estimating outside the data range; unreliable	The trend may not continue
Pre-Q Cloze	P(event) = {{c1::favourable outcomes}} ÷ {{c2::total outcomes}}		
Pre-Q Cloze	Probability scale: 0 = {{c1::impossible}}; 1 = {{c2::certain}}		
Pre-Q Cloze	\(P(\text{not }A) = {{c1::1-P(A)}}\)		
Pre-Q Cloze	Relative frequency = {{c1::successes}} ÷ {{c2::trials}}		
Pre-Q Basic	More trials: what happens to relative frequency?	Gets closer to the theoretical probability	
Pre-Q Cloze	Expected frequency = {{c1::probability}} × {{c2::number of trials}}		
Pre-Q Cloze	Tree diagram: {{c1::multiply}} along branches (AND); {{c2::add}} between paths (OR)	Branches from one point sum to 1	
Pre-Q Basic	Tree diagram without replacement?	Second-stage probabilities change; denominators drop by 1	
Pre-Q Cloze	P(at least one) = {{c1::1 − P(none)}}		Use the complement
Pre-Q Cloze	\(P(A \mid B) = \frac{ {{c1::P(A \text{ and } B)}} }{ {{c2::P(B)}} }\)	"Probability of A given B"	Restrict to B
Pre-Q Basic	Conditional probability from a table: denominator?	Total of the "given" group, not the grand total	
Pre-Q Cloze	Pie chart angle = {{c1::frequency ÷ total}} × {{c2::360°}}		
Pre-Q Basic	Bar chart vs histogram?	Bar chart has gaps between categories; histogram has none	
Pre-Q Basic	Histogram with unequal widths: bar area shows?	Frequency	
Pre-Q Cloze	Frequency density = {{c1::frequency}} ÷ {{c2::class width}}	Label the vertical axis "Frequency density"	
Pre-Q Basic	Frequency for part of a histogram class?	Frequency density × width of that part	Assume values are spread evenly
Pre-Q Basic	Median of an even number of values?	Mean of the middle two	
Pre-Q Basic	Best average when there are outliers?	Median (the mean is pulled by extremes)	Not the mean
Pre-Q Cloze	Mean from a frequency table \(= \frac{ {{c1::\sum fx}} }{ {{c2::\sum f}} }\)		f = frequency
Pre-Q Cloze	Estimated mean (grouped): use each class {{c1::midpoint}} as x	\(\frac{\sum f\times\text{midpoint}}{\sum f}\)	
Pre-Q Basic	Why is a grouped mean only an estimate?	Uses midpoints; actual values are unknown	
Pre-Q Basic	Cumulative frequency: plot against?	The upper class boundary	Not the midpoint
Pre-Q Cloze	Cumulative frequency curve: \(Q_1\) at {{c1::\(\frac n4\)}}, median at {{c2::\(\frac n2\)}}, \(Q_3\) at {{c3::\(\frac{3n}{4}\)}}	Read across, then down	Not \(\frac{n+1}{2}\)
Pre-Q Cloze	pth percentile: read across at {{c1::\(\frac{p}{100}\times n\)}}		
Pre-Q Basic	Why is the IQR better than the range?	It ignores extreme values	
Pre-Q Cloze	Box plot: {{c1::minimum}}, {{c2::lower quartile}}, {{c3::median}}, {{c4::upper quartile}}, {{c5::maximum}}	Box from Q1 to Q3	5 values
Pre-Q Basic	How to compare two distributions?	Average (median) and spread (IQR), with numbers and context	2 comments
Pre-Q Cloze	Correlation: points slope up {{c1::positive}}; slope down {{c2::negative}}; no pattern {{c3::zero}}	Strong = points close to a line	
Pre-Q Basic	Line of best fit by eye?	Follows the trend through the mean point; equal points either side	
Pre-Q Basic	Does correlation prove causation?	No
