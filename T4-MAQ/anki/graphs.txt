Pre-Q Basic	Asymptote?	A line a curve approaches but never meets	
Pre-Q Basic	Tangent to a curve?	A line touching the curve at one point, in its direction	
Pre-Q Basic	Gradient (of a line)?	Steepness: change in y ÷ change in x	
Pre-Q Cloze	\(y = mx + c\): m is the {{c1::gradient}}, c is the {{c2::y-intercept}}		
Pre-Q Cloze	Gradient from two points: \(m = \frac{ {{c1::y_2-y_1}} }{ {{c2::x_2-x_1}} }\)		
Pre-Q Cloze	Length of a line segment \(= \sqrt{ {{c1::(x_2-x_1)^2+(y_2-y_1)^2}} }\)		Pythagoras
Pre-Q Cloze	Midpoint \(= \left(\frac{ {{c1::x_1+x_2}} }{2}, \frac{ {{c2::y_1+y_2}} }{2}\right)\)		Average the coordinates
Pre-Q Cloze	Line through \((x_1, y_1)\) with gradient m: \(y - y_1 = {{c1::m(x - x_1)}}\)		
Pre-Q Basic	How to find c once m is known?	Substitute a known point into y = mx + c	
Pre-Q Cloze	Parallel lines have {{c1::the same}} gradient		
Pre-Q Cloze	Perpendicular lines: \(m_1m_2 = {{c1::-1}}\), so \(m_2 = {{c2::-\frac{1}{m_1} }}\)	Neither line vertical	
Pre-Q Cloze	Distance–time graph: gradient = {{c1::speed}}; horizontal line = {{c2::stationary}}		
Pre-Q Cloze	Speed–time graph: gradient = {{c1::acceleration}}; area under = {{c2::distance travelled}}		
Pre-Q Basic	Area under a linear speed–time graph?	Split into triangles and rectangles	Trapezia also work
Pre-Q Basic	Deceleration on a speed–time graph?	A negative gradient (state the deceleration as positive)	
Pre-Q Basic	Conversion graph of proportional quantities?	A straight line through the origin	
Pre-Q Basic	Shape of \(y = ax^2\)?	Parabola: minimum if a &gt; 0, maximum if a &lt; 0	
Pre-Q Basic	Shape of \(y = ax^3\)?	Cubic with rotational symmetry about the origin	
Pre-Q Basic	Shape of \(y = \frac ax\)?	Two branches; both axes are asymptotes	Reciprocal graph
Pre-Q Basic	Shape of \(y = \frac{a}{x^2}\) (a &gt; 0)?	Two branches, both above the x-axis	
Pre-Q Basic	Shape of \(y = a^x\) (a &gt; 1)?	Exponential: rises ever more steeply, never reaches 0	
Pre-Q Basic	Graph of \(y = ax^0\)?	Horizontal line y = a	
Pre-Q Basic	How to draw a curve from a table of values?	Plot each point; join with one smooth curve	No straight segments
Pre-Q Basic	How to solve f(x) = k graphically?	Draw y = k; read x where it cuts the curve	
Pre-Q Basic	How to solve f(x) = g(x) graphically?	Draw both graphs; read x at the intersections	
Pre-Q Basic	How to estimate a curve's gradient at a point?	Draw the tangent; Δy ÷ Δx from a large triangle on it	Ruler touches, never cuts
Pre-Q Basic	Gradient at a maximum or minimum?	Zero	
Pre-Q Basic	Exact gradient of a curve from its equation?	Differentiate	
Pre-Q Cloze	\(y = ka^x\) shows growth if {{c1::a &gt; 1}} and decay if {{c2::0 &lt; a &lt; 1}}		Compare a with 1
Pre-Q Basic	Shape of an exponential decay graph?	Falls steeply, then flattens towards the x-axis	
Pre-Q Cloze	Exponential growth: {{c1::compound interest}}, {{c2::bacterial growth}}; decay: {{c3::depreciation}}, {{c4::radioactive decay}}		
Pre-Q Cloze	Region boundary: {{c1::solid}} line for ≤ or ≥; {{c2::dashed}} line for &lt; or &gt;		Is the line included?
Pre-Q Basic	Which side of a boundary line is the region?	Test a point not on the line, usually the origin	
Pre-Q Basic	Regions question: which part to shade?	Read the instruction; often the unwanted region	
Pre-Q Basic	Linear programming: where is the maximum or minimum?	At a corner (vertex) of the region	Test each one
Pre-Q Basic	How to find inequalities from a drawn region?	Find each line's equation; test an inside point for the sign
