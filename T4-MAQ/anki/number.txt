Pre-Q Basic	Natural numbers?	The counting numbers, from 1 upwards	
Pre-Q Basic	Integer?	Whole number: positive, negative or zero	
Pre-Q Basic	Prime number?	Has exactly two factors: 1 and itself	
Pre-Q Basic	Rational number?	Can be written \(\frac ab\) with integers a and b, b ≠ 0	
Pre-Q Basic	Irrational number?	Cannot be a fraction; its decimal never ends or repeats	Examples: π, √2
Pre-Q Basic	Surd?	A root that cannot simplify to a rational number	
Pre-Q Basic	HCF?	Highest common factor: largest number dividing all of them	
Pre-Q Basic	LCM?	Lowest common multiple: smallest number they all divide into	
Pre-Q Cloze	HCF from prime factors: multiply the {{c1::lowest}} power of each {{c2::shared}} prime		
Pre-Q Cloze	LCM from prime factors: multiply the {{c1::highest}} power of {{c2::every}} prime		
Pre-Q Basic	\(x \in A\) vs \(x \notin A\)?	x is an element of A vs x is not	
Pre-Q Basic	\(A'\) (sets)?	Complement: everything not in A	
Pre-Q Basic	\(\varnothing\)?	The empty set	
Pre-Q Basic	\(\mathcal{E}\)?	The universal set	
Pre-Q Basic	\(A \subseteq B\) vs \(A \subset B\)?	Subset vs proper subset	
Pre-Q Basic	\(A \cup B\)?	Union: in A or B (or both)	
Pre-Q Basic	\(A \cap B\)?	Intersection: in both A and B	
Pre-Q Basic	\(n(A)\)?	Number of elements in set A	
Pre-Q Basic	\(A \cap B'\) vs \(A' \cap B'\)?	A only vs outside both circles	Not in B vs in neither
Pre-Q Basic	Set-builder notation \(\{x : \ldots\}\) reads?	"The set of x such that …"	
Pre-Q Basic	Venn diagram: which region to fill first?	The intersection, then work outwards	
Pre-Q Cloze	\(n(A \cup B) = {{c1::n(A)+n(B)}} - {{c2::n(A\cap B)}}\)		The overlap is counted twice
Pre-Q Basic	How to order fractions, decimals and percentages?	Convert all to decimals, then compare	
Pre-Q Basic	How to convert a recurring decimal to a fraction?	Let x = decimal; multiply by 10 or 100; subtract x; solve	\(0.\dot7 = \frac79\)
Pre-Q Cloze	Order of operations: {{c1::brackets}}, {{c2::indices}}, {{c3::division and multiplication}}, {{c4::addition and subtraction}}		B-I-DM-AS
Pre-Q Cloze	\(a^m\times a^n = a^{ {{c1::m+n}} }\), \(a^m\div a^n = a^{ {{c2::m-n}} }\), \((a^m)^n = a^{ {{c3::mn}} }\)		
Pre-Q Cloze	\(a^0 = {{c1::1}}\) and \(a^{-n} = {{c2::\frac{1}{a^n} }}\)	\(a \neq 0\)	
Pre-Q Cloze	\(a^{\frac1n} = {{c1::\sqrt[n]{a} }}\) and \(a^{\frac mn} = {{c2::\left(\sqrt[n]{a}\right)^m}}\)		The denominator is the root
Pre-Q Cloze	Negative fractional index: {{c1::reciprocal}}, {{c2::root}} and {{c3::power}}, in any order		3 steps
Pre-Q Cloze	Standard form \(A\times10^n\): {{c1::\(1 \leqslant A &lt; 10\)}} and n is {{c2::an integer}}	Adjust A back into range after calculating	
Pre-Q Cloze	\(\sqrt{ab} = {{c1::\sqrt a\sqrt b}}\) and \(\sqrt{\frac ab} = {{c2::\frac{\sqrt a}{\sqrt b} }}\)		
Pre-Q Cloze	Rationalise: \(\frac{1}{\sqrt a} = {{c1::\frac{\sqrt a}{a} }}\)		Multiply top and bottom by \(\sqrt a\)
Pre-Q Cloze	Rationalise: \(\frac{1}{a-\sqrt b} = \frac{ {{c1::a+\sqrt b}} }{ {{c2::a^2-b}} }\)	Multiply top and bottom by the conjugate	Difference of two squares
Pre-Q Basic	How to simplify a surd?	Take out the largest square factor	e.g. \(\sqrt{48} = \sqrt{16}\sqrt3\)
Pre-Q Basic	How to write \(a\sqrt b\) as an entire surd?	Square a and bring it inside: \(\sqrt{a^2b}\)	
Pre-Q Basic	Which surds can be added?	Only like surds (same number under the root)	\(\sqrt{a+b} \neq \sqrt a+\sqrt b\)
Pre-Q Basic	Significant figures: count from?	The first non-zero digit	
Pre-Q Basic	How to estimate a calculation?	Round every number to 1 s.f., then calculate	
Pre-Q Basic	Bounds of a measurement?	Half a unit either side of the stated accuracy	e.g. to the nearest 10: ±5
Pre-Q Cloze	Upper bound of \(a+b\) or \(a\times b\): use {{c1::both upper bounds}}	Lower bound: both lower bounds	
Pre-Q Cloze	Bounds of \(a-b\): upper = {{c1::\(a_{max}-b_{min}\)}}; lower = {{c2::\(a_{min}-b_{max}\)}}		Make the gap biggest, then smallest
Pre-Q Cloze	Bounds of \(a\div b\): upper = {{c1::\(a_{max}\div b_{min}\)}}; lower = {{c2::\(a_{min}\div b_{max}\)}}		
Pre-Q Basic	How to share a quantity in a ratio?	Find one part (total ÷ sum of parts), then multiply	
Pre-Q Cloze	Direct proportion: \(y = {{c1::kx}}\); inverse proportion: \(y = {{c2::\frac kx}}\)		
Pre-Q Basic	First step in a variation question?	Find k from the given pair of values	
Pre-Q Cloze	Average speed = {{c1::total distance}} ÷ {{c2::total time}}	Never the mean of the speeds	
Pre-Q Cloze	Percentage change = {{c1::change}} ÷ {{c2::original}} × 100		
Pre-Q Cloze	Multiplier to increase by r%: {{c1::\(1+\frac{r}{100}\)}}; to decrease by r%: {{c2::\(1-\frac{r}{100}\)}}		
Pre-Q Basic	Reverse percentage (find the original)?	Divide by the multiplier	Not adding the percentage back on
Pre-Q Cloze	Price before a sales tax (e.g. GST) = price including tax ÷ {{c1::(1 + tax rate)}}		A reverse percentage
Pre-Q Basic	Currency conversion: multiply or divide by the rate?	Multiply going the quoted way; divide coming back	
Pre-Q Cloze	Simple interest: \(I = \frac{ {{c1::Prt}} }{100}\)	r% per year, t in years; same amount each year	
Pre-Q Cloze	Compound interest: value \(= P\left( {{c1::1+\frac{r}{100} }} \right)^{ {{c2::n}} }\)		
Pre-Q Basic	Compound interest formula gives?	The total value, not the interest (subtract P)	
Pre-Q Cloze	Depreciation: value \(= P\left( {{c1::1-\frac{r}{100} }} \right)^n\)
