# Number

## Types of number

| Type | Meaning | Examples |
|---|---|---|
| Natural | counting numbers | 1, 2, 3, … |
| Integer | whole, positive, negative or zero | −3, 0, 7 |
| Prime | exactly two factors | 2, 3, 5, 7, 11 |
| Square | $n^2$ | 1, 4, 9, 16 |
| Rational | can be written $\tfrac{a}{b}$ with integers, $b \neq 0$ | $\tfrac35$, 0.25, $0.\dot3$ |
| Irrational | cannot | $\pi$, $\sqrt2$ |
| Real | all of the above | — |

1 is **not** prime (it has one factor). 2 is the only even prime.

## Squares, cubes, roots and directed numbers

Squares: 1, 4, 9, 16, 25, … Cubes: 1, 8, 27, 64, 125, … The symbol $\sqrt{\ }$ means the **positive** root: $\sqrt{49} = 7$. A cube root can be negative: $\sqrt[3]{-64} = -4$.

**Directed numbers.** Subtracting a negative adds. A temperature rising from −7 °C to 4 °C has risen by $4-(-7) = 11$ °C.

**Ordering.** Convert everything to decimals, then compare. To order $\tfrac35$, 0.62, 58% and $\tfrac{7}{11}$, write them as 0.6, 0.62, 0.58 and 0.636…, giving $58\% < \tfrac35 < 0.62 < \tfrac{7}{11}$.

## Prime factorisation, HCF and LCM

Split repeatedly until only primes remain:

$$84 = 2^2 \times 3 \times 7 \qquad 126 = 2\times3^2\times7$$

- **HCF** — multiply the **lowest** power of each shared prime: $2^1\times3^1\times7^1 = 42$
- **LCM** — multiply the **highest** power of every prime appearing: $2^2\times3^2\times7 = 252$

Check: $\text{HCF}\times\text{LCM} = 42\times252 = 10584 = 84\times126$ ✓

## Sets and Venn diagrams

| Notation | Meaning |
|---|---|
| $x \in A$ | $x$ is an element of $A$ |
| $x \notin A$ | $x$ is not an element of $A$ |
| $A'$ | complement — everything not in $A$ |
| $\varnothing$ | empty set |
| $\mathcal{E}$ | universal set |
| $A \subseteq B$ | $A$ is a subset of $B$ |
| $A \subset B$ | $A$ is a proper subset of $B$ |
| $A \cup B$ | union — in $A$ **or** $B$ |
| $A \cap B$ | intersection — in $A$ **and** $B$ |
| $n(A)$ | number of elements in $A$ |

Set-builder: $C = \{x : 2 \leqslant x \leqslant 9\}$ reads "the set of $x$ such that $x$ is between 2 and 9 inclusive".

For two-set Venn problems, always fill the **intersection first**, then work outwards. Suppose the universal set has 30 elements, set $A$ has 18, set $B$ has 14, and their intersection has 8. Then $A$ only = 10, $B$ only = 6, and neither = $30 - (10+8+6) = 6$.

With **three sets**, start at the centre (in all three), then the rest of each two-set overlap, then each "only" region, and finally the region outside all three.

## Fractions, decimals, percentages

Convert freely:

$$\frac{3}{8} = 0.375 = 37.5\%$$

**Recurring decimal to fraction.** Let $x = 0.\dot7 = 0.777\ldots$ Then $10x = 7.777\ldots$, so $10x - x = 7$, giving $x = \tfrac79$.

For two repeating digits, multiply by 100: $x = 0.\dot{2}\dot{7} \Rightarrow 100x - x = 27 \Rightarrow x = \tfrac{27}{99} = \tfrac{3}{11}$.

**Four rules with mixed numbers.** Convert to improper fractions first, and for $\div$ multiply by the reciprocal:

$$2\tfrac13 \div 1\tfrac12 = \frac{7}{3}\div\frac{3}{2} = \frac{7}{3}\times\frac{2}{3} = \frac{14}{9} = 1\tfrac59$$

Order of operations: **brackets, indices, division and multiplication, addition and subtraction**.

## Indices and standard form

$$a^m\times a^n = a^{m+n} \qquad \frac{a^m}{a^n} = a^{m-n} \qquad (a^m)^n = a^{mn}$$
$$a^0 = 1 \qquad a^{-n} = \frac{1}{a^n} \qquad a^{1/n} = \sqrt[n]{a} \qquad a^{m/n} = \left(\sqrt[n]{a}\right)^m$$

$$16^{3/4} = \left(\sqrt[4]{16}\right)^3 = 2^3 = 8 \qquad 25^{-1/2} = \frac{1}{\sqrt{25}} = \frac15$$

**Standard form** is $A\times10^n$ with $1 \leqslant A < 10$ and $n$ an integer.

- $47\,300 = 4.73\times10^4$
- $0.000\,082 = 8.2\times10^{-5}$
- $(3\times10^5)\times(4\times10^{-2}) = 12\times10^3 = 1.2\times10^4$ — adjust $A$ back into range

## Surds

A surd is a root that cannot be simplified to a rational number, such as $\sqrt2$. The rules:

$$\sqrt{ab} = \sqrt a\times\sqrt b \qquad \sqrt{\frac ab} = \frac{\sqrt a}{\sqrt b} \qquad \sqrt a\times\sqrt a = a$$

Only like surds add: $3\sqrt5+2\sqrt5 = 5\sqrt5$, but $\sqrt2+\sqrt3$ does not simplify.

**Simplify.** Take out the largest square factor: $\sqrt{48} = \sqrt{16\times3} = 4\sqrt3$, and $\sqrt{68} = \sqrt{4\times17} = 2\sqrt{17}$.

**Entire surd.** Square the number outside and bring it inside: $6\sqrt5 = \sqrt{36\times5} = \sqrt{180}$.

**Expand** like ordinary brackets, then simplify:

$$2\sqrt3\left(\sqrt3+2\sqrt6\right) = 6 + 4\sqrt{18} = 6+12\sqrt2$$
$$\left(1-2\sqrt3\right)\left(1+5\sqrt3\right) = 1+5\sqrt3-2\sqrt3-30 = 3\sqrt3-29$$

**Rationalise the denominator.** Multiply top and bottom by the surd. If the denominator is $a-\sqrt b$, multiply by $a+\sqrt b$ instead, so the difference of two squares removes the root:

$$\frac{6}{\sqrt3} = \frac{6\sqrt3}{3} = 2\sqrt3 \qquad \frac{4}{3-\sqrt5} = \frac{4\left(3+\sqrt5\right)}{9-5} = 3+\sqrt5$$

## Approximation and bounds

Round to a given number of **significant figures** (count from the first non-zero digit) or **decimal places**.

$0.040\,78$ to 2 s.f. is 0.041; to 3 d.p. is 0.041.

**Estimation.** Round every number to 1 s.f., then calculate without a calculator:

$$\frac{38.7\times0.52}{9.8} \approx \frac{40\times0.5}{10} = 2 \qquad \text{(exact value 2.05)}$$

**Bounds.** A value stated to a given accuracy lies within half a unit of that accuracy:

A length of 4.6 cm to 1 d.p. has $4.55 \leqslant l < 4.65$.

For a rectangle $4.6 \times 7.2$ cm (both 1 d.p.):

- maximum area $= 4.65 \times 7.25 = 33.7$ cm²
- minimum area $= 4.55 \times 7.15 = 32.5$ cm²

For **division**, the maximum of $a/b$ uses $a_{max}/b_{min}$ — the biggest numerator over the smallest denominator.

## Ratio and proportion

**Dividing in a ratio.** Share \$450 in the ratio 4 : 5 : 6. Total parts = 15, so one part = \$30, giving \$120 : \$150 : \$180.

**Increase or decrease by a ratio.** Increase 80 in the ratio 7 : 5 means $80\times\tfrac75 = 112$.

**Direct proportion** — $y = kx$. Double $x$ and $y$ doubles.
**Inverse proportion** — $y = \tfrac{k}{x}$. Double $x$ and $y$ halves.

Also met: $y \propto x^2$, $y \propto \sqrt{x}$, $y \propto \tfrac{1}{x^2}$. Always find $k$ from the given pair first.

*Example.* $y \propto \tfrac{1}{x^2}$ and $y = 12$ when $x = 2$. Then $k = 12\times4 = 48$, so $y = \tfrac{48}{x^2}$, and when $x = 4$, $y = 3$.

**Work problems** use inverse proportion: more workers, fewer days. It takes 6 men 4 days to dig a hole 3 m deep. That is $6\times4 = 24$ man-days for 3 m, or 8 man-days per metre. A 7 m hole needs 56 man-days, so 10 men take $56\div10 = 5.6$ days.

**Average speed** $=\dfrac{\text{total distance}}{\text{total time}}$ — never the average of two speeds.

## Percentages

| Task | Method |
|---|---|
| Percentage of a quantity | multiply by the decimal: 17% of 240 = $0.17\times240 = 40.8$ |
| One quantity as a % of another | $\dfrac{\text{part}}{\text{whole}}\times100$ |
| Percentage change | $\dfrac{\text{change}}{\text{original}}\times100$ |
| Increase by 15% | $\times1.15$ |
| Decrease by 15% | $\times0.85$ |
| **Reverse percentage** | **divide** by the multiplier |

**Reverse percentage.** A coat costs \$84 after a 30% reduction. Original $= 84 \div 0.70 = \$120$. (Adding 30% back to \$84 gives \$109.20 — wrong.)

Selling price \$95 includes a 25% profit on cost. Cost $= 95\div1.25 = \$76$.

**GST** in New Zealand is 15%, so a price including GST is the reverse of $\times1.15$. A \$1750 ticket including GST costs $1750\div1.15 = \$1521.74$ before GST, so the GST is \$228.26.

## Money, time and finance

**Currency conversion.** Multiply by the rate when going the way the rate is quoted, divide when going back. At £1 = US\$1.27, £350 = US\$444.50 and US\$600 = £472.44.

**Clocks and timetables.** 14:35 is 2:35 pm. To find a duration across the hour, count up to the next hour then on: 09:47 to 13:20 is 13 min + 3 h 20 min = 3 h 33 min.

**Simple interest.** $I = \dfrac{Prt}{100}$ — the same amount each year.

**Compound interest.**

$$\text{value} = P\left(1+\frac{r}{100}\right)^n$$

\$2000 at 4% for 5 years: $2000\times1.04^5 = \$2433.31$, so the interest is \$433.31. Simple interest would give only \$400.

**Depreciation** uses the same formula with a negative rate, i.e. $\times(1-\tfrac{r}{100})^n$. A \$18 000 car losing 15% a year is worth $18000\times0.85^3 = \$11\,054.25$ after 3 years.

**Exponential growth and decay** follow the same pattern: bacteria doubling every hour give $N = N_0\times2^t$; a population growing 3% a year gives $P_0\times1.03^t$.
