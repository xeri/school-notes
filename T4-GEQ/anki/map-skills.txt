Pre-Q Basic	Scale (maps)?	Ratio of map distance to ground distance	
Pre-Q Basic	Easting?	Vertical grid line numbered west to east; quoted first	
Pre-Q Basic	Northing?	Horizontal grid line numbered south to north; quoted second

Pre-Q Basic	How to give a 6-figure grid reference?	Add tenths east then tenths north within the square	Each tenth 0–9

Pre-Q Basic	Bearing?	Clockwise angle from grid north, written as three digits

Pre-Q Cloze	Bearings: E = {{c1::090°}}, S = {{c2::180°}}, W = {{c3::270°}}		
Pre-Q Basic	Back bearing?	Bearing in the opposite direction: add or subtract 180°	e.g. from 060°
Pre-Q Basic	Contour?	Line joining points of equal height	
Pre-Q Basic	Contour interval?	Height difference between successive contours	
Pre-Q Basic	Spot height?	Point on a map marked with its exact height	
Pre-Q Basic	Close vs widely spaced contours	Close: steep slope. Wide: gentle or flat	
Pre-Q Basic	Convex slope (contours)?	Contours closer together at the bottom	
Pre-Q Basic	Concave slope (contours)?	Contours closer together at the top	
Pre-Q Basic	Contour V pointing uphill?	Valley	
Pre-Q Basic	Contour V pointing downhill?	Spur	
Pre-Q Basic	Concentric closed contours?	Hill or summit	
Pre-Q Basic	Col (saddle)?	Low point on a ridge between two summits	
Pre-Q Basic	Gradient?	Steepness of a slope	
Pre-Q Cloze	Gradient = {{c1::vertical rise ÷ horizontal distance}}		Convert map cm to metres first
Pre-Q Basic	How to express gradient as "1 in x"?	Horizontal distance ÷ vertical rise	
Pre-Q Basic	Cross-section?	Side-on profile of the ground along a chosen line	
Pre-Q Cloze	Drawing a cross-section: mark {{c1::contour crossings}} on a paper edge; plot {{c2::heights}} on the graph; join with a {{c3::smooth curve}}		3 steps
Pre-Q Basic	Vertical exaggeration?	Vertical scale ÷ horizontal scale of a cross-section

Pre-Q Basic	Dry point (map evidence)?	Higher ground above floodplain or marsh
