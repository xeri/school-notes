# Geography study guide (exam Wed 4 Nov)

What to learn first, why, and how to learn each kind of content. This is a priority order, not a timetable: work down the list and stop wherever you run out of time. Everything above the line you reach will have been the highest-value work.

## Methods by kind of content

### Models (Burgess, Hoyt, DTM, Rostow, Butler and the rest)

1. Read the row in the [models index](../notes/models-index.md) and look at the diagram.
2. Close the page. **Draw the diagram from memory**, with a title, labelled axes or zones and a key.
3. Say the three-step explanation aloud: cause → process → result.
4. Add one strength, one limitation and one named place where it fits or fails.
5. Check against the page. Redraw anything you got wrong; tick it only when it is right first time.

### Named processes and landforms (meanders, spits, longshore drift, subduction)

1. Read the sequence on the topic page.
2. Draw it as numbered stages (the existing diagrams show how).
3. Say the 3-step explanation, using the exact process names: hydraulic action, abrasion, attrition, solution.
4. Check, especially the step the mark scheme reserves: the flood that cuts the neck of an ox-bow, the change of coastline direction for a spit, hard rock **over** soft rock for a waterfall.

### Solutions (defences, policies, strategies)

- Learn each as **name + how it works + one strength + one weakness**. Mark schemes give one mark for the official name and the second for how it works; a description of what it looks like earns nothing.
- Keep river methods and coastal methods apart; river methods are not credited in a coastal answer.

### Case studies

1. Pick one case from [CASE-STUDIES.md](../CASE-STUDIES.md).
2. **Blurt**: on blank paper, write every fact you can — place, date, scale, two or three figures, causes, effects, responses, evaluation.
3. Check against the file. Circle what you missed.
4. Repeat later with only the circled facts.
5. Be ready to use each case for more than one question: the [overlaps page](../notes/overlaps.md) lists which case fits which question.

### Essays

- Write **one plan per theme from memory**: a position, four SDEEL paragraphs, each with a developed named example, and a conclusion that says what the judgement depends on.
- Check each plan against the level descriptors in [Exam technique](../notes/exam-technique.md): Level 3–4 needs place-specific detail and evaluation, not tags.
- Likely families, from the school's essay list:
  - **Theme 1:** living in hazardous places (tectonic, coastal, river); how denudation forms and removes landforms; river flood management, hard vs soft; global and New Zealand climate variation; coastal opportunities, hazards and management.
  - **Theme 2:** ageing, declining or youthful populations; migration ("always bad", types, push–pull, obstacles); "Auckland is overpopulated"; rapid urban growth in HICs and LICs; the history of urbanisation.
  - **Theme 3:** choosing development indicators (HDI vs HPI); farming methods and dairy expansion; investing in tourism despite shocks; industry vs environmental damage; renewable energy for LICs.

### Map skills and data

- Practise rather than memorise: six-figure grid references, 16-point directions, bearings, distances along a curved road, gradient, cross-sections.
- Quote figures **with units** (and "thousands" where the axis says so); read graphs precisely.
- Use map evidence only when the question says so.
