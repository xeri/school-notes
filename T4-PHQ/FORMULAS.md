# Physics formulas

**No formula sheet is provided in the exam.** Every equation below must be recalled.

## Measurement

| Quantity | Equation |
|---|---|
| Average | $\bar{x} = \dfrac{\sum x}{n}$ |
| Gradient | $\dfrac{\Delta y}{\Delta x}$ |
| Resultant of perpendicular vectors | $R = \sqrt{a^2 + b^2}$ (Pythagoras) |

## Motion

| Quantity | Equation |
|---|---|
| Average speed | $v = \dfrac{d}{t}$ |
| Acceleration | $a = \dfrac{v-u}{t}$ |
| SUVAT | $v = u + at$ |
| | $s = ut + \tfrac12 at^2$ |
| | $s = \tfrac12(u+v)t$ |
| | $v^2 = u^2 + 2as$ |

Free fall: $g = 9.81$ m/s².

## Forces

| Quantity | Equation |
|---|---|
| Weight | $W = mg$ |
| Newton's second law | $F = ma$ |
| Hooke's law | $F = kx$ |
| Circular motion | $F = \dfrac{mv^2}{r}$ |
| Moment | $M = Fd$, $d$ = perpendicular distance from pivot to line of action |
| Principle of moments | $\sum M_{cw} = \sum M_{acw}$ |
| Momentum | $p = mv$ |
| Impulse | $Ft = \Delta p = mv - mu$ |
| Force as rate of change of momentum | $F = \dfrac{\Delta p}{t}$ |

## Density, energy, pressure

| Quantity | Equation |
|---|---|
| Density | $\rho = \dfrac{m}{V}$ |
| Work | $W = Fd = \Delta E$ |
| Kinetic energy | $E_k = \tfrac12 mv^2$ |
| Potential energy | $\Delta E_p = mg\Delta h$ |
| Power | $P = \dfrac{\Delta E}{t}$ |
| Efficiency | $\dfrac{\text{useful out}}{\text{total in}}\times100\%$ |
| Pressure | $P = \dfrac{F}{A}$ |
| Liquid pressure | $P = \rho g h$ |

## Thermal

| Quantity | Equation |
|---|---|
| Kelvin conversion | $T/\mathrm{K} = T/^\circ\mathrm{C} + 273$ |
| Thermal capacity | $C = mc$ (J/K) |
| Specific heat capacity | $Q = mc\Delta T$ |
| Specific latent heat | $Q = ml$ |
| Heat exchange | energy lost by hot body = energy gained by cold body |
| Boyle's law | $pV = \text{constant}$ |
| Gay-Lussac | $\dfrac{P}{T} = \text{constant}$ |
| Charles | $\dfrac{V}{T} = \text{constant}$ |
| Combined gas law | $\dfrac{P_1V_1}{T_1} = \dfrac{P_2V_2}{T_2}$ |

Gas laws: fixed mass of gas, $T$ in kelvin; $p$ and $V$ in any consistent units.
Specific heat capacity of water: about 4200 J/(kg·K). $c$ is in J/(kg·K); $l$ is in J/kg.

## Waves

| Quantity | Equation |
|---|---|
| Wave equation | $v = f\lambda$ |
| Period | $T = \dfrac{1}{f}$ |
| Law of reflection | angle of incidence = angle of reflection |
| Refractive index | $n = \dfrac{\sin i}{\sin r}$ |
| | $n = \dfrac{c}{v} = \dfrac{\text{speed in vacuum}}{\text{speed in medium}}$ |
| Critical angle | $n = \dfrac{1}{\sin c}$ |
| Speed of sound (echo) | $v = \dfrac{2d}{t}$ |

Speed of EM waves in a vacuum: $c = 3.0\times10^8$ m/s.
Audible range: 20 Hz – 20 000 Hz.

## Electricity

| Quantity | Equation |
|---|---|
| Current | $I = \dfrac{Q}{t}$ |
| Resistance | $R = \dfrac{V}{I}$ |
| Resistivity | $R = \dfrac{\rho L}{A}$ |
| Series resistance | $R_T = R_1 + R_2$ |
| Parallel resistance | $R_T = \dfrac{R_1R_2}{R_1+R_2}$ |
| Power | $P = IV$ |
| Energy | $E = IVt$ |
| Cable loss | $P = I^2R$ |
| Potential divider | $V_{out} = V_{in}\dfrac{R_2}{R_1+R_2}$ |
| Transformer turns | $\dfrac{V_p}{V_s} = \dfrac{N_p}{N_s}$ |
| Transformer power | $I_pV_p = I_sV_s$ |

1 V = 1 J/C.

## Atomic and space

| Quantity | Equation |
|---|---|
| Nuclide notation | $^{A}_{Z}X$, neutrons $= A - Z$ |
| Fraction remaining | $\left(\tfrac12\right)^n$ after $n$ half-lives |
| Orbital speed | $v = \dfrac{2\pi r}{T}$ |
| Hubble's law | $H_0 = \dfrac{v}{d}$ |
| Age of Universe | $\dfrac{1}{H_0}$ |

Light year $\approx 9.5\times10^{15}$ m. $H_0 \approx 2.2\times10^{-18}$ s⁻¹.
