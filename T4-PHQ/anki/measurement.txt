Pre-Q Basic	Scalar?	Quantity with magnitude only	
Pre-Q Basic	Vector?	Quantity with magnitude and direction	
Pre-Q Basic	Accuracy (measurement)?	How close a measurement is to the true value	Not the same as precision
Pre-Q Basic	Precision (measurement)?	How close repeated readings are to each other	Not the same as accuracy
Pre-Q Basic	Parallax error?	Misreading a scale by viewing it at an angle	
Pre-Q Basic	Normal (light and surfaces)?	Construction line at 90° to a surface	
Pre-Q Basic	Resultant (vectors)?	Single vector with the same effect as all combined	
Pre-Q Basic	Range of an instrument?	The span of values it can measure	
Pre-Q Basic	Resolution of an instrument?	Smallest change it can display

Pre-Q Basic	When to convert units in a calculation?	Before substituting into the equation	
Pre-Q Basic	How to convert km/h to m/s?	× 1000 ÷ 3600 (i.e. ÷ 3.6)	km to m, then h to s
Pre-Q Basic	How to convert cm³ to m³?	× 10⁻⁶	Three dimensions, each ÷ 100
Pre-Q Basic	How to convert g/cm³ to kg/m³?	× 1000	
Pre-Q Cloze	Precision: metre rule {{c1::±1 mm}}; vernier calliper {{c2::±0.1 mm}}; micrometer screw gauge {{c3::±0.01 mm}}		Each about 10× finer
Pre-Q Cloze	Voltmeter connected in {{c1::parallel}}; ammeter in {{c2::series}}		
Pre-Q Basic	How to avoid parallax error?	Eye level, perpendicular to the scale mark	
Pre-Q Basic	Choosing a measuring instrument?	Range covers the quantity; resolution fine enough	
Pre-Q Cloze	Average = {{c1::sum of the readings}} ÷ {{c2::number of readings}}		
Pre-Q Basic	Do repeat readings remove systematic error?	No; they only reduce random error	
Pre-Q Basic	How to improve accuracy?	Remove systematic errors: zero check, calibration	Think what shifts all readings
Pre-Q Basic	How to improve precision?	Finer instrument; repeat and average	
Pre-Q Basic	Precise but inaccurate readings?	Tightly grouped round the wrong value (systematic error)	
Pre-Q Cloze	Gradient = {{c1::Δy}} ÷ {{c2::Δx}}	Units: y-units ÷ x-units	Use a large triangle
Pre-Q Basic	Distance vs displacement	Distance: path length (scalar). Displacement: straight line + direction (vector)	
Pre-Q Cloze	Scalar–vector pairs: distance → {{c1::displacement}}; speed → {{c2::velocity}}; mass → {{c3::weight}}		Give the vector partner
